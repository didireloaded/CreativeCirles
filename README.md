# Creative Circle UI

A responsive, UI-only PWA redesign for The Creators. The experience is shaped around the supplied references: a cinematic creator feed, a light productivity workspace, soft glass navigation, and a restrained coral accent.

## Included screens

- Creator-orbit welcome screen
- Home feed with stories and local like/save interactions
- Discover with search, filters, creators, communities, and events
- Create flow for posts, projects, stories, and events
- Local drafts presented as a Saved Ideas card stack
- Inbox with messages and collaboration requests
- Creator profile with work, projects, and profile editing
- Workspace with overview, calendar, reminders, collaborators, and insights
- Responsive mobile, tablet, and desktop layouts
- PWA manifest, icons, and offline shell caching

This is intentionally a front-end preview. Content is sample data, interactions are stored locally, and backend, AI, payments, job marketplace, and live communication services are not connected yet.

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## Verify

```bash
npm run typecheck
npm run lint
npm run build
```
